- Users should be able to toggle a JSON editor view for any financial function to enable editing as JSON rather than as a form.
- Users should be able to 1-click download their entire simulation as JSON be able to import in the same way.
- Users should be able to generate a share UUID, i.e. just a record in the backend linking to the underlying simulation UUID so a user can send a friend /share/<shareUUID> and the friend can see the content of the underlying simulation without being able to modify it.
- Users should be able to register an account to protect their sim. On their unique URI, they can add a username and password to correlate that sim with their username. once a sim is protected, the backend will check for authentication before serving the content of the sim. If the authentication fails the user is redirected to the home page. At the home page a new user has the option to create an account which will also create their default sim, or just create a sim with a unique URL.
- Since implenting financial functions isn't easy we need a prebuilt library of functions that the user can simply select from as an alternative to -- or base for -- creating their own.
- When debugging or creating a financial functions users need the ability to create debugging plots for variables within their functions.
